# ROOM RAIDEN テーマのサイト側設定

テーマはページと設定の中身を持たない。次を Ghost 側で用意しないと、デザインにある
セクションが出ない。

## 固定ページ

| slug               | 用途                                | 出ないと起きること                       |
|--------------------|-------------------------------------|------------------------------------------|
| `news`             | トップの News セクションの本文      | News セクションが丸ごと消える            |
| `about`            | About ページ                        | `page-about.hbs` が当たらず通常ページ表示 |
| `terms-of-service` | 利用規約                            | フッターのリンクが 404                   |
| `privacy-consent`  | プライバシーポリシー                | 同上。Portal の同意ゲートも通らなくなる  |
| `tokushoho`        | 特商法に基づく表示                  | フッターのリンクが 404                   |

`news` はトップに本文だけを差し込む。見出しの「News」はテンプレート側が出すので、
ページ本文には見出しを書かない。

`about` の本文はそのまま About ページに出る。Figma では「ROOM RAIDEN とは」と
「Contents」を `h2` で置いている。上部の「About」の見出しと集合写真は
テンプレート側が出すので、本文には書かない。

## テーマ設定（Design > Site-wide）

| 設定                | 用途                                     |
|---------------------|------------------------------------------|
| `announcement_text` | ヘッダー下のお知らせバー。空ならバーごと出ない |
| `announcement_url`  | お知らせバーのリンク先。空ならリンクにしない |

## Settings > Social accounts

X・YouTube・Instagram を入れるとフッターのアイコンが出る。空のものは出ない。
